# CSS に定義を持たない className の許可リスト
#
# check-css-classes.mjs が参照する。1行1件、クラス名のあとに理由を書く。
#
# **まとめて登録しないこと。** この検査が生まれたのは、`.table-scroll` という
# 存在しないクラスで幅広の表を包み、overflow-x が効かないまま
# ページ全体が横に 435px はみ出してモバイルで縮小表示になっていたためである。
# 正しくは `.article-table-scroll` で、単語ひとつ違っていた。
#
# 登録する前に必ず確認すること:
#   - 似た名前の既存クラスがないか（取り違えなら直す）
#   - スタイルを持たないことが本当に意図か

loading            読み込み中の入れ替え用。インラインスタイルで完結しており CSS 定義を持たない
lang-notice        英語版の注記。すべてインラインスタイルで指定している
detail-related     関連記事セクションの目印。余白はインラインスタイル、中身は子要素のクラスで整えている
guide-section--vibe      BEM の修飾子。見た目は .guide-section が持ち、こちらは節の種別を示す目印
guide-section--glossary  同上
