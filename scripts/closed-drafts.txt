# ## なぜこのファイルが要るのか
#
# 棚卸しは「記事がすべて main にあるか」で判定する。公開せずにクローズした
# 下書きは、記事が main に入らないため**永久に「未決着」のまま報告され続ける。**
#
# そしてブランチの削除は、エージェントの実行環境からはできない
# （git proxy が ref の削除を拒否し、GitHub MCP にも削除ツールが無い）。
# ブラウザからの手作業が要るため、削除されるまでの間ずっと鳴り続ける。
#
# CLAUDE.md は「クローズする場合は理由を1行残す」と定めているが、
# **その1行を残す場所が無かった。** ここがその場所である。
#
# ## 書き方
#
# 決着の理由を具体的に書くこと。「不要」では、同じネタを来週また調査して
# また保留にする、を防げない。**何に取って代わられたのかを書く。**
